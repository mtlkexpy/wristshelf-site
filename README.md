# Wristshelf website

Static public information, support and privacy pages for Wristshelf, a standalone Apple Watch Audiobookshelf player.

No application source, server credentials or private test data are included. Serve this directory as static files; GitHub Pages uses the main branch root. Custom domain: wristshelf.fourbees.net.

Original artwork and site content are provided under the MIT license.

The About page shares a short Christian gospel message. Example media visible in the player screenshot is not included with Wristshelf. Narnia cover artwork belongs to its respective owners and is excluded from the MIT license; its display implies no affiliation or endorsement.
